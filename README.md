# VERTER — сжечь

Интерактивный сайт для мероприятия: человек пишет негативные эмоции на листе,
лист сминается, летит в компьютер VERTER, компьютер сгорает до горстки пепла.

## Сайт в интернете

Каждый пуш в ветку `main` автоматически публикуется на GitHub Pages
(workflow `.github/workflows/pages.yml`). Публикацию можно запустить и вручную:
вкладка Actions → «Публикация на GitHub Pages» → Run workflow.

Послания на опубликованном сайте сохраняются в браузере того, кто пишет,
и выгружаются на том же устройстве через `Ctrl + Shift + E`.

## Запуск локально

1. Открыть `index.html` в **Google Chrome** (двойной клик или перетащить в окно).
2. Нажать **F**, чтобы включить полный экран.
3. Первый клик по тумбе включает звук (браузер не даёт играть звук без клика).

Интернет не нужен: вся графика и звуки генерируются кодом.

## Горячие клавиши

| Клавиши | Что делает |
|---|---|
| `F` | полный экран |
| `M` | выключить/включить звук |
| `Ctrl + Shift + E` | панель посланий: скачать .txt / .json, очистить |

## Послания

Каждое послание сохраняется в браузере на этом компьютере (localStorage)
в момент нажатия «поджечь». Выгрузка — через `Ctrl + Shift + E`.

Важно: послания живут в профиле Chrome. Не очищайте историю/данные сайтов
и не открывайте сайт в режиме инкогнито, пока не скачали файл.
После мероприятия скачайте .txt и при желании очистите список.

## Автосброс

- Если на листе ничего не пишут 3 минуты — сайт возвращается к тумбе.
- Финальный кадр с пеплом сам сбрасывается через 90 секунд.

## Структура

- `js/art.js` — вся графика (тумба, ящик, руки, комок, компьютер, спички, пепел)
- `js/main.js` — сценарий и тайминги анимаций
- `js/fire.js` — огонь, дым и искры
- `js/audio.js` — синтез звуков
- `js/store.js` — сохранение и выгрузка посланий
- `assets/` — лапки котика
- `website/` — референсы (только локально, в репозиторий не попадают)
